#### Code changes (pattern applied to all 4 repos)

```python
# Added to each config.py
SECRETS_ARN: str = ""

def _load_secrets(arn: str) -> dict:
    try:
        import boto3
        sm = boto3.client("secretsmanager", region_name="ap-northeast-2")
        val = sm.get_secret_value(SecretId=arn)
        return json.loads(val["SecretString"])
    except Exception as e:
        logger.error("Failed to load secrets from %s: %s", arn, e)
        return {}

@lru_cache
def get_settings() -> Settings:
    s = Settings()
    if s.SECRETS_ARN:
        secrets = _load_secrets(s.SECRETS_ARN)
        # override each secret field...
    return s

settings = get_settings()
```

`myblog_backend` already had this pattern; added `EDGE_SECRET` override only (2 lines).

### 4. Startup guard — fail fast on empty secrets

Added `ValueError` inside `get_settings()` when `SECRETS_ARN` is set but required secrets resolve to empty string.

```python
missing = [k for k, v in {
    "SPOTIFY_CLIENT_ID": s.SPOTIFY_CLIENT_ID,
    "SPOTIFY_CLIENT_SECRET": s.SPOTIFY_CLIENT_SECRET,
}.items() if not v]
if missing:
    raise ValueError(f"Required secrets missing after Secrets Manager load: {missing}. Check SECRETS_ARN and IAM policy.")
```

**Before**: Lambda cold start succeeds → Spotify 401 at first SQS message → indefinite DLQ retry loop  
**After**: Lambda cold start raises `ValueError` → immediately visible in CloudWatch init logs

| Repo | PR | Fields guarded |
|---|---|---|
| myblog_worker | #8 | `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET` |
| myblog_music | #10 | `DATABASE_URL`, `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET` |

Both CI: success. Guard only runs when `SECRETS_ARN` is set — local dev unaffected.
