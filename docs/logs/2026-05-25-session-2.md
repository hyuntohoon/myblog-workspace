## Completed Work

### CICD-1 — Frontend CI/CD fix (myblog_front #6)

#### 1. pnpm version mismatch

**Problem**: `pnpm/action-setup@v3` used `version: 9` but `package.json` declared `"packageManager": "pnpm@10.6.3"`. pnpm@9 cannot read a pnpm@10 lockfile — CI silently regenerated it every run, meaning the lockfile was never actually verified.

**Fix**: Changed `version: 9` → `version: 10`.

---

#### 2. Quality gate — lint + astro check before deploy

**Problem**: `pnpm build` ran directly with no prior quality check. Type errors and lint failures were invisible in CI.

**Fix**: Split single `deploy-front` job into two jobs:

```yaml
jobs:
  check:           # pnpm lint + pnpm exec astro check
    ...
  deploy:
    needs: check   # only runs if check passes
    ...
```

Before the gate could be added, two pre-existing blocking issues had to be fixed:

**ESLint config was completely broken:**
- `eslint.config.js` used `plugins: ['unused-imports']` — the old `.eslintrc` format. ESLint 9 flat config requires a plugin object, not a string array. `pnpm lint` was failing with a `ConfigError` on every run.
- Fix: Imported `eslint-plugin-unused-imports` and changed to `plugins: { 'unused-imports': unusedImports }`.
- Ran `eslint --fix` to normalize style across the codebase (~62 files, mostly trailing commas, arrow parens, quotes).

#### 3. Cache-Control strategy

**Problem**: All S3 objects received `no-cache, no-store` including `_astro/**` files which have content-hashed names and should be cached permanently.

**Fix**: Three separate `aws s3 cp` steps with correct headers per path pattern:

| Path | Cache-Control |
|------|---------------|
| `_astro/**` | `public, max-age=31536000, immutable` |
| `pagefind/**` | `public, max-age=3600` |
| `*.html`, `sitemap*.xml`, `rss.xml` | `no-cache, no-store, must-revalidate` |

---

#### 4. pnpm store cache

**Problem**: Every CI run performed a full `pnpm install` with no caching.

**Fix**: Added `actions/cache@v4` in both `check` and `deploy` jobs:

```yaml
- name: Cache pnpm store
  uses: actions/cache@v4
  with:
    path: ~/.local/share/pnpm/store
    key: pnpm-${{ runner.os }}-${{ hashFiles('pnpm-lock.yaml') }}
    restore-keys: pnpm-${{ runner.os }}-
```
