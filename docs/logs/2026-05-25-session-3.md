### 1. publisher-github Function URL 삭제

**문제**: `publisher-github` Lambda에 공개 Function URL이 존재 (`AuthType: NONE`, `AllowOrigins: *`).  
정상 트래픽 경로는 `CloudFront → API GW (JWT authorizer) → Lambda`인데, Function URL이 열려 있어 API GW의 Cognito JWT 인증을 완전히 우회 가능. `x-origin-verify` (EDGE_SECRET) 하나만이 방어선.

**조치**: AWS CLI로 Function URL 삭제.

```
aws lambda delete-function-url-config --function-name publisher-github
# 검증: FunctionUrlConfigs: [] 확인
```

Function URL은 Terraform에 없던 수동 생성 리소스. 삭제해도 API GW 경로에 영향 없음.
