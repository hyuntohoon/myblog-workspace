DOCUMENT 2 — Astra round-6 comparative (defects and proposals)

## 3. 지속되는 결함과 원인 분류

실제 프롬프트 조건이 없으므로 아래는 **관찰된 발생 경로에 따른 진단**입니다. 프롬프트 유발이라고 단독 확정할 결함은 없습니다.

| 반복 결함 | 관찰 범위 | 분류와 근거 |
|---|---|---|
| 가공 요약을 직접 원문 확인으로 표시 | S03–S06 | **모델/하네스 유발.** 요약 반환 경로와 최종 접근 상태 표기가 직접 충돌합니다. 하네스가 요약을 제공한 것과 모델이 이를 격상한 것을 구분해야 합니다. |
| 접근 가능한 권위 크레딧 행 미사용 | S01·S03–S07 | **모델/하네스 유발.** 탐색·출처 선택의 실패가 관찰됩니다. 권위 행 접근 자체가 불가능했던 사례는 아닙니다. |
| 다른 범위의 수치를 가짜 상충으로 만들거나 실제 차이를 성급히 해소 | S01–S06 | **혼합 가능성.** 비교 추론 오류는 확인됩니다. 상태 분류 규칙이 충분히 정의되었는지는 알 수 없어 프롬프트 기여는 미확정입니다. |
| 분모·제외·별칭 통합의 불일치 | S01·S02·S06 | **혼합 가능성.** 계산·범위 관리 문제와 집계 규칙 정의 문제가 연결되지만, 실제 프롬프트의 책임은 입증되지 않았습니다. |
| 화자 또는 개별 출처의 경계 소실 | S04·S06의 화자 승격, S07의 매체 연결 문제 | **모델/하네스 유발.** 요약을 문장으로 재구성하거나 통합 검색 출력을 개별 매체에 배정하는 과정에서 발생했습니다. |
| 제한·재확인 요청의 반복 | S02·S04·S05 | **혼합 가능성.** 반복은 확인되지만, 출력 구조나 길이 지시가 원인인지는 알 수 없습니다. |

S03의 “등재 없음”과 S07의 미확인 표현은 동일하게 취급하면 안 됩니다. 전자는 제공 관계와 충돌하지만, 후자는 공동 기여 정보와 개인별 분담 미확정이 양립할 수 있습니다.

## 4. 다음 제한 라운드의 프롬프트 변경안

1. **출처 상태 규칙 정의:** 직접 열람, 가공 fetch 요약, 검색 요약, 재인용을 구분하고 주장별로 표시합니다. 나중의 내용 검증이 생산 당시 접근 경로를 소급 변경하지 않도록 합니다.
2. **크레딧 규칙 일반화:** R-a–R-c를 본문 규칙으로 통합합니다. 권위 행의 판본·트랙·원 역할·인원을 보존하고, 미확보 시 접근 실패와 미탐색을 구분합니다.
3. **상충 규칙 정의:** 대상·역할·기간·분모·배타성을 대조한 뒤 양립 불가능할 때만 상충으로 표시합니다. “관찰된 차이”와 “차이의 원인 미확인”은 함께 유지할 수 있게 합니다.
4. **집계 규칙 정의:** 기존 역할·분자·분모·제외·출처 공개에 이름 통합 기준을 명시합니다. 미확인 별칭은 합치지 않으며, 집계와 표·청취 질문에 같은 범위를 적용합니다.
5. **귀속·추적 규칙 일반화:** 각 인용에 화자 계층과 회수 위치를 연결합니다. 통합 요약을 개별 매체에 임의 배정하지 않고, 확보된 부분 정보와 남은 공백을 구분합니다.
