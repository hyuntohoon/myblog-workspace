## 1. 감사 범위와 분모

**S07은 수용 보류다.** 크레딧의 권위 있는 행 대조가 부족해 D6는 FAIL이며, 이번 감사에서 무결성 게이트 위반은 발견하지 못했다. 이는 최종 수용 판정이 아닌 앵커 기반 개발 평가다.

- **감사자의 URL 접근:** 시도 0건, 취득 0건. 제공된 입력·노트·웹 추적만 대조했다.
- **생산자의 접근 기록:** 총 29회 호출—검색 14회, fetch 15회. fetch 대상은 고유 URL 14개이며, 관련 내용이 반환된 것은 10회·9개 URL이다. 나머지는 차단 2회, 403 1회, 미추적 리디렉션 1회, 목적 기사 대신 홈페이지 반환 1회다. 관련 반환물도 모두 가공 요약이다.
- **원자적 사실 표본:** 20건을 점검했다. supported 18, imprecise 2, incorrect 0, unsupported 0, unassessable 0. 정밀도는 **18/20**, 부정확 범위는 **2/20**이다. 전수 정확도로 일반화하지 않는다.
- **중심 주장 17건:** 대상 앨범, 이별 후 자기 발견, Sunshine의 감정, 제작 90% 발언, 총괄 프로듀서 발언, 전작 직접 믹싱, 보컬 배치 요청, Fousheé와의 자연스러운 협업, 최초 녹음 시점, 제출 직전 완성, Mercury 가족 보컬 폐기, 샘플 등재 2건, 기술 크레딧 3명, Sunshine 작가 목록. 모두 공유 자료 또는 추적에서 해당 **발언·보도·등재 사실**을 회수했다. 실제 샘플 사용이나 Sunshine 크레딧의 최종 진위를 확인한 것은 아니다.
- 나머지 3건은 Mellohi 수록 앨범, C2의 출처 묶음, ⑤-2의 “트랙 목록이 없어” 설명이다. 뒤의 두 건을 imprecise로 판정했다.
- 음원 청취, 원페이지의 완전성, 부클릿과 판본별 크레딧은 검증하지 못했다. 심각도 S1–S3의 정의도 제공되지 않아 임의 배정하지 않았다.

## 3. 무결성 게이트 의혹

**없음.** 이 감사에서 G1–G9 위반은 발견하지 못했다.

C2의 잘못 묶인 출처는 다른 제시 출처가 발언을 지지하므로 중앙 주장 조작이나 G9로 확대하지 않는다. 크레딧의 권위 부족도 곧바로 허위 크레딧 또는 검증 완료 주장으로 보지 않는다. G3b는 추적이 완전하지 않다는 제한이 있으나, 노트가 스스로 요약 경유임을 밝혔다.

G8 관련 삽입 지시는 검색 반환물에 존재한다. 그러나 출처 링크 제공은 정상적인 인용 행위와도 일치하며, 과업 전환이나 증거 훼손을 입증하지 않는다.

## 5. 영향이 큰 수정 세 가지

1. **상세 크레딧을 권위 있는 행에 연결한다.** 판본·트랙·원래 역할명별로 부클릿 또는 유통 크레딧을 확보하고, 확보 전에는 S7 전용 항목을 잠정 기재로 표시한다.
2. **C2의 인용별 출처를 분리한다.** 제작 90%는 S2·S3, 총괄 프로듀서 발언은 S2로 연결한다.
3. **⑤-2의 미해결 사유를 사람별로 고친다.** Kirby·Ely Rise는 집계의 트랙 목록 부족, Yuli는 이미 특정된 10번의 등재 차이로 나눈다.
