# Stage B 비교 보정 결과 (S01–S13)

과제 설명에는 "한 검토자 13건, 다른 검토자 7건"이 있다고 되어 있습니다. 그런데 이번에 받은 보고서는 S01–S13의 13건뿐입니다. 그래서 이 13건만 보정했습니다. 나머지 7건은 받지 않아 보정에 넣지 못했습니다.

## 1. 일관성 점검과 수준 변경

### 적용한 보정 규칙 (기존 앵커를 해석한 것이며 새 기준은 아님)

- **D4: 출처가 막혔는지, 구절이 없는지를 구분합니다.**
  - 감사자가 출처에 접근하지 못한 경우는 그 구절만 판정 불가로 둡니다. 이것은 FAIL이 아닙니다(S04, S06, S09).
  - 출처를 열었는데 인용 구절이 그 안에 없는 경우에만 C-D4-FAIL을 적용합니다(S13).
  - 인용된 다른 출처에서 구절이 회수된 경우는 BORDERLINE입니다(S07).
- **D4: 중심 인용이 다음 둘 중 하나에 해당하면 BORDERLINE입니다.** 이는 "회수는 되지만 시간이 걸림"에 해당합니다.
  - 번역문만 있고 원문이 병기되지 않음(§4.4)
  - 위치를 생산자 도구의 줄번호로만 표시함
- **D5: 접근 경로(1차·중계·미확인)만 평가합니다.**
  - 매체를 잘못 지목한 것은 D2/D4에서 이미 다룹니다. D5에서 다시 감점하지 않습니다.
  - 상태 표기가 없거나, 결과에 영향 없이 경로를 과장했으면 BORDERLINE입니다(A/C 앵커 그대로).
- **D5: 하네스에 따라 1차 여부가 다릅니다.**
  - 줄번호가 붙은 원문 열람(open)은 M1의 "읽음(primary)"으로 봅니다.
  - WebFetch가 모델로 처리해 돌려준 요약은 "중계"입니다.
  - 그래서 S03, S04, S05, S10의 "원문 확인" PASS와 S01, S02, S12의 BORDERLINE은 서로 모순되지 않습니다.

### 수준은 유지하고 근거만 고친 것

- **S09 D2 (PASS 유지):** "후렴이 됐다"를 범위 확대로 본 지적은 철회합니다. S03, S04, S10에서 GRAMMY 원문에 "It became the chorus"가 있음을 확인했습니다.
- **S05 D4 (PASS 유지):** 번역문만 있는지 확인할 증거가 보고서에 없어서 바꾸지 않았습니다. 다음 라운드에서 다시 점검할 항목입니다.
- **S02 D3 (FAIL 유지)와 G5(low):** 게이트 주장은 다시 열지 않았습니다. S12 K5는 같은 내용이지만 absent로 판정했습니다. 생산자가 받은 중계 텍스트가 이를 Lacy의 발언으로 제시했기 때문이라 두 판정은 서로 모순되지 않습니다.
- **S13 D4 (FAIL 유지):** 중심 주장 C5의 따옴표 구절이 지목된 출처를 열었는데도 그 안에서 회수되지 않았습니다.

## 4. 다음 라운드 프롬프트 변경안 (5건)

1. **[원문 확인] 라벨을 정의합니다.** 도구가 처리하지 않은 페이지 텍스트를 받은 경우에만 [원문 확인]을 씁니다. 모델이 처리한 fetch 요약은 [가공 요약 경유], 검색 결과는 [검색 결과 경유]입니다. 이는 M1을 라벨 규칙으로 일반화한 것입니다. 라벨은 출처 단위가 아니라 주장 단위로 붙입니다.
2. **증거 발췌 규칙을 일반화합니다.** 모든 중심 인용에 원어 구절을 그대로 넣고 번역을 병기합니다. 위치는 원문 구절 앵커나 절 제목처럼 이식 가능한 표지로 씁니다. 도구 줄번호를 위치로 쓰는 것은 삭제합니다.
3. **크레딧 전사 규칙을 정의합니다.** 명명된 행을 쓸 때는 노트에 나오는 인물의 역할 문자열을 트랙별로 그대로 옮깁니다. 요약 열과 범례에서도 역할을 합치거나 이름을 바꾸지 않습니다. 일부만 골랐다면 선별 기준을 적습니다.
4. **귀속 규칙을 "실제로 본 경로" 기준으로 일반화합니다.** 각 주장의 출처는 생산자가 텍스트를 실제로 받은 문서입니다. 검색 요약이 지목한 매체는 "요약이 X에 귀속함"으로만 적습니다. "일부", 곡·앨범 단위 같은 범위 한정어는 원문 그대로 유지합니다. 배타 진술은 확인하지 못했으면 [미확인]으로 표시합니다.
5. **접근 기록 요건을 바꿉니다.** 검색 횟수, HTTP 상태, 실패 경로는 도구 로그에서 옮길 수 있을 때만 적고, 아니면 생략합니다. 기억에 기댄 횟수 보고 요구는 삭제합니다.
