DOCUMENT 2 — Astra round-3 comparative (defects and proposals)

### 3. 지속되는 반복 결함과 원인 판단

실제 프롬프트 조건과 생산자 정보가 없으므로, 아래는 **관찰된 작동 방식에 대한 잠정 분류**입니다. 특정 조건이나 생산자에 대한 인과 추정은 하지 않습니다.

| 반복 결함 | 관찰 사례 | 잠정 분류 |
|---|---|---|
| 가공 요약을 원문 확인으로 승격 | S01·S02·S12 | **혼합.** 하네스의 가공 출력과 모델의 검증 상태 명명이 맞물립니다. 같은 접근 제약에서도 정확히 표시한 사례가 있어 하네스만의 문제는 아닙니다. |
| 여러 명제를 출처 하나에 일괄 귀속 | S07·S12·S13 | **모델/하네스 유발.** 혼합·생략된 요약을 문장별로 분해하지 못한 문제가 관찰됩니다. |
| 권위 있는 행 없이 상세 크레딧 전달 | S01·S02·S07·S08·S11·S13 | **모델/하네스 유발.** 원행 접근 제약과 대체 자료를 사용하는 방식이 함께 작용합니다. |
| 이미 제공된 정보를 ‘없음·미상·비교 불가’로 처리 | S02·S07·S13 | **모델 유발.** 기존 입력과 최종 표의 대조 실패라는 직접 증거가 있습니다. |
| 범위가 다른 진술을 배타성·충돌·비상충으로 확정 | S01·S02·S12·S13 | **모델 유발.** 자료의 범위를 넘는 해석이 반복됩니다. |
| 검색 횟수·커버리지 기준 불일치 | S01·S11·S13 | **모델 유발.** 기록·표와 요약 수치를 일치시키지 못합니다. |
| 접근 한계·근거의 기능 없는 반복 | S01·S07·S08·S11·S13 | **혼합 가능성.** 반복되는 문서 구조와 생성 방식의 상호작용일 수 있지만, 프롬프트 유발 여부는 확인되지 않았습니다. |

기자 서술을 직접 발언으로 올리는 결함과 리뷰·평점을 제작 사실의 증거로 전용하는 결함은 이번 7건에서 반복 확인되지 않았습니다.

### 4. 다음 제한 라운드의 프롬프트 변경 제안

실제 프롬프트 문구는 제공되지 않았으므로, 아래는 **기존 평가 규칙의 정의·일반화·중복 요구 삭제안**입니다.

1. **접근 상태 규칙 정의:** ‘원문 확인’을 생산자가 직접 검사한 비가공 본문·보존 캡처에 한정합니다. 검색·가공 fetch는 경유 자료로 표시하고, 사실 지원 여부와 접근 경로를 분리합니다.
2. **귀속·추적 규칙 일반화:** 하나의 출처 묶음 안에서도 명제별 화자 계층·출처·위치를 연결합니다. 위치나 출처가 불명확하면 그 범위를 명시하며, 자료의 진술 강도를 넘어 배타성이나 충돌을 확정하지 않습니다.
3. **크레딧 규칙 정의:** 판본·트랙·원래 역할 문자열·권위 있는 행의 연결을 기준으로 삼습니다. 해당 연결이 없는 크레딧은 잠정 등재 정보로 구분하고, 서로 다른 역할·집계 범위를 임의로 통합하지 않습니다.
4. **부재·집계 규칙 일반화:** ‘없음·미상·비교 불가’와 모든 수치를 확정하기 전에 제공 입력 및 최종 표를 대조합니다. 집계에는 대상·분자·분모·제외·출처를 명시합니다.
5. **반복 서술 요구 삭제:** 동일 접근 제한과 검증 결론을 여러 절에서 다시 설명하는 요구는 제거합니다. 상세 설명은 한곳에 두고, 주장별 상태 표시는 필요한 위치에 유지합니다.
