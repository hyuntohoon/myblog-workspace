### 1. 감사 분모와 접근 한계

- **생산자 추적:** 검색 18회, URL fetch 13회. 서로 다른 13개 URL 중 내용 응답 10개, 실패 3개다. 성공 응답은 S1–S9의 9개 URL과 Apple의 `/album/static/1631909576`; 실패는 Genius Mercury, WhoSampled Mercury, Discogs master다. 성공 응답도 원문 전체가 아니라 가공된 발췌·요약이다.

- 별도로 실제 크레딧 상충 4건(Kirby 프로듀서·작가, Ely Rise 프로듀서, Yuli 작가)과 샘플 관계 2건은 **검증 불가 6건**으로 기록한다. 등재 내용 자체는 확인되지만 실제 역할·관계는 해결되지 않았다. 전체 검사 항목 37개 중 6개이며, 모두 중심 또는 고위험이다.

### 5. 영향이 큰 수정 세 가지

1. **접근 경로를 바로잡기:** ‘원문 확인’을 ‘해당 페이지 fetch 요약·발췌로 확인’으로 바꾸고, 직접 발언이라는 화자 분류와 직접 원문 열람 여부를 분리한다.
2. **커버리지 재계산:** 「Mercury」를 포함해 인터뷰 출처 3/10, 재인용 포함 4/10으로 고친다. 제작 과정만 집계하려면 그 정의를 먼저 밝히고 표에도 동일하게 적용한다.
3. **크레딧 범위 보존:** 원래 역할 문자열과 확인 가능한 트랙을 유지한다. ‘90%’와 신스 5/9의 대립을 제거하고, 실제 DB 간 역할 차이와 독립적으로 미확인인 샘플 관계만 후속 확인 대상으로 남긴다.

- **D8:** 이별·편집·협업·전작 제작 기간은 앨범에 맞는 맥락이다. 다만 제작 비중과 신스 참여를 대비한 청취 질문은 수정해야 한다. 오너의 실제 유용성 평가는 없다.
