## 1. 감사 범위와 분모

**S06은 수용 보류가 적절하다.** 이번 감사에서 무결성 게이트 위반은 발견하지 못했지만, 일부 핵심 크레딧과 판본 대응은 미확인 상태다.

- **감사자의 URL 접근:** 시도 0, 확보 0. 웹 도구 없이 공유 입력과 보존된 추적만 대조했다.
- **생산자의 접근:** 검색 17회, 서로 다른 URL에 대한 fetch 15회. 내용 요약 확보 10건, 내용 미확보 5건이다. 미확보는 WhoSampled 2건, Genius 차단 1건, Rolling Stone 리디렉션 1건, 유료 응답 1건이다. 가공되지 않은 원문 확보는 0건이다.
- **주장 표본:** 중심 주장 30개를 점검했다. 대상 식별·발매 정보 6개, C1–C8의 의도·협업·제작 주장 20개, 샘플 등재 주장 2개, Sunshine 작가 명단·드럼 크레딧 2개다. 이름별 분할로 크레딧 명단의 분모를 늘리지 않았다.
- **판정:** 지원됨 28, incorrect 0, imprecise 0, unsupported 0, unassessable 2. 평가 가능한 주장 정밀도는 **28/28**, 전체 표본 중 미확인은 **2/30**이다. 지원 판정은 명시된 **발언·보도·데이터베이스 등재 사실**에 대한 것으로, 실제 제작 사실을 독립적으로 확정했다는 뜻이 아니다.
- **미확인 2개:** ③ Sunshine의 작가 명단과 Karriem Riggins 드럼 참여. S4 요약에 해당 내용은 있지만 권위 있는 크레딧 행과 대상 Spotify 판본의 대응을 확인할 수 없다. 모두 중심·고위험 크레딧이다. 표본 밖 ④·⑤의 크레딧 차이 역시 해결되지 않았다.
- 원문 인용의 최종 충실성, 실제 오디오, 기준일 당시 페이지 상태는 독립 검증하지 못했다. S1 등의 인용문은 **생산자가 받은 요약 안에서는 회수된다**. 접근 불가 자체를 오류나 조작으로 계산하지 않았다.

- C5의 “유일한 피처링”은 trace 4에 있는 Lacy의 발언으로 제시된다. Matt Martians가 표시된 메타데이터(trace 5·9)와 긴장은 있지만, 생산자의 독립적인 배타적 사실 확정으로 보기는 어렵다.

- 자료 누락만으로 G2·G3b를 의심하지 않는다. 별도의 미해결 게이트 의혹은 없다.

## 5. 영향이 큰 수정 세 가지

1. **크레딧의 권위 있는 행을 확보한다.** Sunshine 및 Kirby·Rise·Matt Martians·Yuli 관련 항목에 대상 판본, 트랙, 원래 역할, 출처를 연결한다. 확보 전에는 후보 정보로 유지한다.
2. **“유일한 피처링”의 범위를 정리한다.** Lacy의 발언, Fousheé의 피처링 표기, Matt Martians의 공동 명의·제작 역할을 나란히 제시하고 배타적 결론은 유보한다.
3. **근거 경로와 탐색을 정돈한다.** “검색 결과 경유”를 실제 요약 접근 방식으로 고치고, ③의 크레딧 차이 참조를 ④로 수정하며, 반복되는 접근 제한은 한곳으로 모은다.
