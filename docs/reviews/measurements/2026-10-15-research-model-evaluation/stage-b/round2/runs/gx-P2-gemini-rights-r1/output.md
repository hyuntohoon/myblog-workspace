## ④ 미해결·추가 확인

1. **역할 상충과 판본 연결.** 입력에는 Genius의 전체 트랙별 역할 행이 없고 S2와 집계가 다르다. 부클릿 검색으로 대조 가능한 원본을 확보하지 못했다. 원래 API 행과 실물 인서트를 확보해 `Producer`부터 대조해야 한다. ‘Sunshine’의 유통 확인은 Genius 매칭 문제를 해결한 것이 아니다.

2. **샘플 두 관계는 미확인 단서다.** ‘Mercury’→Eddie Kendricks의 ‘Just Memories’, ‘2Gether’→C418의 ‘Mellohi’는 입력 DB 등재다. 해당 Genius 웹페이지는 접근 오류였다. 대체 검색에서 후자는 두 곡이 같은 멜로트론 자료를 썼다는 제보도 나왔지만, 연결된 악기 자료 페이지 역시 접근하지 못했다. 전자는 제작자·권리자 원문을 확보하지 못했다. 원천 파일·사용 구간·권리 표기를 확인하기 전 직접 샘플로 확정하지 않는다. [S8](https://www.reddit.com/r/stevelacy/comments/vzj9u1/)

3. **엔지니어의 작업 설명은 영상 단서가 남는다.** Vinyl.com의 Karl Wingate 인터뷰 소개는 확보했지만 본문에 발언록이 없었다. 별도 영상 검색에서도 직접 답변을 확보하지 못했다. 발매 1주년 회고 영상이므로 재생·전사 후 트랙별 작업 설명만 추가해야 한다. [S9](https://vinyl.com/blogs/featured/karl-wingate-on-steve-lacys-gemini-rights)
